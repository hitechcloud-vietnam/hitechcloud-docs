## Băng thông máy chủ

Lấy thông tin băng thông của máy chủ.

### Yêu cầu HTTP

`GET /service/@id/bandwidth`

### Tham số truy vấn

| Tham số | Kiểu | Mô tả |
|-----------|------|-------------|
| id | int | ID dịch vụ |

### Yêu cầu mẫu

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/bandwidth"
```
