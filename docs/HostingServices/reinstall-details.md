## Reinstall Details

Retrieve installation options for a server.

### HTTP Request

`GET /service/@id/reinstall`

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| id        | int  | Service ID  |

### Example Request

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/reinstall"
```
