## Chi tiết cài lại

Lấy các tùy chọn cài đặt của máy chủ.

### Yêu cầu HTTP

`GET /service/@id/reinstall`

### Tham số truy vấn

| Tham số | Kiểu | Mô tả |
|-----------|------|-------------|
| id | int | ID dịch vụ |

### Yêu cầu mẫu

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/reinstall"
```
