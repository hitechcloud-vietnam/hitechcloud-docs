# Diagnostics Status

Show the status of a diagnostics operation.

### HTTP Request
```
GET /service/@id/diag
```

### Query Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| id        | int  | Service ID   |

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/diag" \
   -H "Authorization: Bearer $token"
```
