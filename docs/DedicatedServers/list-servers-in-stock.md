# List Servers In-stock

List servers currently in stock.

### HTTP Request
```
GET /serverstock
```

### Query Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| id        | int  | Service ID  |

```bash
curl -X GET "https://my.photuesoftware.vn/api/serverstock" \
   -H "Authorization: Bearer $token"
```
