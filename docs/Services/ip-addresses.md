# IP Addresses

List service IP addresses.

### HTTP Request
```
GET /service/@id/ip
```

### Query Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| id        | int  | Service ID   |

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/ip" \
   -H "Authorization: Bearer $token"
```
