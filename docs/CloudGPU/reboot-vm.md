# Reboot VM

Reboot a virtual server.

### HTTP Request
```
PUT /service/@id/vms/reboot
```

### Query Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| id        | int  | Service ID   |

```bash
curl -X PUT "https://my.photuesoftware.vn/api/service/@id/vms/reboot"
```
