# Get Firewall Rules

Retrieve firewall rules for a virtual server.

### HTTP Request
```
GET /service/@id/vms/firewall
```

### Query Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| id        | int  | Service ID   |

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/vms/firewall"
```
