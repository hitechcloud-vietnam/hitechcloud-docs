# Lấy quy tắc tường lửa

Lấy các quy tắc tường lửa của máy chủ ảo.

### Yêu cầu HTTP
```
GET /service/@id/vms/firewall
```

### Tham số truy vấn
| Tham số | Kiểu | Mô tả |
|-----------|------|-------------|
| id | int | ID dịch vụ |

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/vms/firewall"
```
