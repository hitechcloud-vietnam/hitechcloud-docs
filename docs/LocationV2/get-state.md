## Get State

Retrieve states for a given country code.

### HTTP Request

`GET /location_v2/@code/state`

### Query Parameters

| Parameter | Type   | Description    |
|-----------|--------|----------------|
| code      | string | Country Code   |

### Example Request

```bash
curl -X GET "https://my.photuesoftware.vn/api/location_v2/@code/state"
```
