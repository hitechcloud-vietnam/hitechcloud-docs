# Synchronize Domain

Synchronize domain information.

### HTTP Request
```
GET /domain/@id/sync
```

### Query Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| id        | int  | Domain ID   |

```bash
curl -X GET "https://my.photuesoftware.vn/api/domain/@id/sync" \
   -H "Authorization: Bearer $token"
```
