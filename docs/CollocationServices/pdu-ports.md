# Danh sách cổng PDU

Liệt kê các cổng PDU được gán cho một dịch vụ.

### Yêu cầu HTTP
```
GET /service/@id/pdu
```

### Tham số truy vấn
| Tham số | Kiểu | Mô tả |
|-----------|------|-------------|
| id | int | ID dịch vụ |

```bash
curl -X GET "https://my.photuesoftware.vn/api/service/@id/pdu"
```
